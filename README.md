# 🚀 FocusFlow — Task Management Dashboard

**FocusFlow** is a modern, responsive task management dashboard built with HTML, CSS, and JavaScript. It helps users organize tasks, track progress, and improve productivity through a clean and intuitive interface.

## ✨ Features

- ✅ Add, edit, and delete tasks
- 📊 Track task completion and productivity statistics
- ⏱️ Focus timer for productive work sessions
- 🌙 Dark mode
- 🔍 Search and filter tasks
- 💾 LocalStorage for saving tasks in the browser
- 📱 Responsive design for desktop, tablet, and mobile
- 🎨 Modern and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layouts, and responsive design
- **JavaScript** — Interactive features and task management
- **LocalStorage** — Browser-based data persistence

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.
